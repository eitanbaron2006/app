# Emerald Mahjong v8 · Real Nature Audio

Original Mahjong game with six columns, maximum seven rows, four snug-fitting portrait collection slots, matching animations, and stable 100% WebView text zoom.

**Background audio is real downloaded licensed nature recordings, not synthesized audio.**
The build fetches four recordings from Mixkit, filters and compresses them gently for mobile, and embeds the full files inside the offline HTML game. No live network requests are made by the game itself.

Tracks: Flowing Stream (Mixkit 3126), Gentle Rain (Mixkit 1253), Forest Breeze (Mixkit 1213), Quiet Night (Mixkit 1789).

Mixkit Sound Effects Free License: https://mixkit.co/license/modal/sfxFree/
License authorizes sounds incorporated into video games; standalone redistribution of raw sound effects is prohibited. The repository includes download/build references, not individual audio binaries.

Build output: Android APK + standalone offline HTML + metadata, bundled together as GitHub Actions artifact. The APK is a separate app (com.emerald.mahjongv8) because previous debug signing keys were ephemeral.
